跨境物流 AI 质控 Agent

2025 - 至今 · 菜鸟网络

基于大模型的自主 Agent，用于跨境物流工单质量控制。Agent 通过 ReAct 推理、工具调用和 RAG 知识检索自动质检日均 10 万+ 工单，人工质控工作量减少 80%，判定标准一致性从 75% 提升至 95%。

Spring AI ReAct Agent RAG OpenSearch SchedulerX2 ODPS

核心成果

  • 质控覆盖率：15% → 92%
  • 介入时效：48小时 → 2小时
  • RAG 辅助建议采纳率：79%
  • 年化节约人力成本：约120万元
