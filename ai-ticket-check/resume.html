项目概述
主导设计并落地跨境物流 AI 工单智查平台，基于 Multi-Agent 架构实现工单从触发、数据采集、AI 归因推理、话术生成到工单处理的全链路自动化。覆盖跨境电商（CBS）、清关（CCS）、揽收（CFS）、末端分拣（CLS）、空运（CTS）等 6 大业务域，接入 186 个渠道，日均自动化处理工单 3,000+，置信率 99.3%，将人工介入率降至 25%。
核心职责 & 成果
🏗️
架构设计 — 12 模块 Multi-Agent 平台
主导 cross-border-ai-agents 整体架构设计，划分 agent / tool / knowledge / memory / mcp / facade / gateway-call / dal 等 12 个模块，定义模块边界与依赖关系，支撑 6 大业务域 80+ Agent 类
🧠
Agent 编排方案 — IntentDetector + ReAct 循环
设计意图识别 → 多 Agent 路由 → ReactAgent ReAct 循环的三层编排方案。通过 IntentDetector 进行 LLM 驱动的意图分类，MerchantRoutingAgentFactory 路由至对应业务域，CbsReactAgentFactory + 12 种 ThoughtProcessStrategy 驱动推理执行
🎯
QC Task 引擎 — 工单全生命周期管理
设计 QcTaskEngine 引擎，实现主/子任务的创建、CAS 状态流转、依赖编排、人工介入挂起/恢复等全生命周期管理。注册 17 个 MCP 工具，支持 Agent 运行时自主创建和驱动 5 步智查流水线
🔌
工具体系 — 静态 + 动态 + MCP 三层融合
设计 ToolManager 统一注册中心，融合 @CbaaTool 静态扫描、HttpDynamicTool 运行时热加载、DynamicMcpToolsInstaller 标准 MCP 协议三层工具体系，实现工具即插即用
🐕
稳定性保障 — WatchDog + 6 种告警 + 自动恢复
设计 QcTaskWatchDog 每 5 分钟扫描僵死任务，自动重跑（最多 3 次），超限强制失败 + 钉钉告警。构建 6 种告警模板，覆盖处理失败、异常终止、人工介入、僵死积压等场景
📊
业务成果 — 自动化率 75%，置信率 99.3%
平台上线后接入 186 个渠道，累计处理 3,000+ 工单，AI 归因置信率 99.3%，端到端自动化率 75%，显著降低人工成本
💡 技术亮点
SKILL Self-Managed 模式：Agent 通过 MCP 工具自主管理任务生命周期，无需预建子任务；5 步流水线（数据增强→归因推理→协同处理→话术生成→工单处理）全部由 LLM 编排驱动，实现真正的 Agent 自治。配合 WatchDog 兜底 + Human-in-Loop 人工介入机制，兼顾自动化与可控性。

MCP 工具链开发 — 生命周期 + 业务工具

🔧
Tool 框架 — 静态扫描 + 动态热加载
实现 @CbaaTool 注解扫描的 ToolManager 注册中心、HttpDynamicTool 运行时热加载和 DynamicMcpToolsInstaller MCP 标准协议接入，融合 30+ 静态工具 与动态工具统一管理
🐕
WatchDog 自动恢复 + 钉钉告警
开发 QcTaskWatchDog 定时扫描僵死任务（>20min），CAS 安全回收 + 自动重跑（max 3 次）。构建 DingTalkAlertTemplate 6 种告警模板 + IdeasDingtalkNotifyService HMAC-SHA256 签名推送
🌐
多渠道 Facade 接入层
开发 HSF Provider（QcTaskRemoteService）、MetaQ Consumer（QcSubTaskMsgListener / QcTaskResumeMsgListener）、DingTalk Listener 和 REST Controller 四类入口，实现多渠道统一接入
💡 技术亮点
SKILL Self-Managed 模式下的 ReAct 循环：Agent 通过 17 个 MCP 工具自主创建/驱动子任务，5 步流水线全部由 LLM 编排。引擎层面实现 CAS 乐观状态流转 + 弹性线程池异步调度（core=4, max=16, CallerRunsPolicy），配合 3 次异常重试和 WatchDog 兜底，确保高可用。
